※ v11 은 v10(표 방식)을 "읽기 쉬운 if/else if" 로 바꾼 버전입니다.
   하는 일은 같고, 확장 방법만 더 쉬워졌습니다.


■ 하는 일
──────────────────────────────────────────────────────────────────────
  ① 기존 문장을 그대로 읽어서 동작  (Piano.mode, Trash.mode 등)
  ② 해시값이 들어오면 AI 값도 동작
  ③ 두 가지가 한 코드에서 동시에 동작


══════════════════════════════════════════════════════════════════════
 ★★ AI 값 늘리는 법 — aiDispatch() 안의 else if 를 복사
══════════════════════════════════════════════════════════════════════

  지금 등록된 AI 값:
  ─────────────────────────────────────────────────────────────────
    if (cmd.equals("1NubidaAi") ... )   →  9번 서보 (160 → 10)
    else if (cmd.equals("2NubidaAi") ...) →  7번 서보 ( 10 → 160)


  ▶ 3번을 추가하려면: 아래 블록을 복사해서 주석을 풀면 끝
  ─────────────────────────────────────────────────────────────────

    else if (cmd.equals("3NubidaAi") || cmd.startsWith("3Nubida") || cmd.equals("3")) {
      aiServo3.attach(5);                    // ← 새 서보 핀 (원하는 핀)
      aiWhich = 3;                           // ← 스캔 번호
      aiScan = true; aiLast = millis(); aiPhase = 0;
      aiP = 160; aiDir = -1; aiStart = 160; aiEnd = 10;
      aiServo3.write(aiP);
      Serial.println(F("[AI] 3NubidaAi — 5번 스캔 시작"));
      return true;
    }

  ★ 실제 파일에는 이 블록이 **주석으로 이미 들어있습니다**.
     `*` 만 지우면 바로 활성화됩니다. (3번·4번 예시 두 개 준비됨)

  ★ 서보 객체도 미리 만들어 뒀습니다:
      Servo aiServo1;  // 9번
      Servo aiServo2;  // 7번
      Servo aiServo3;  // 5번  ← 새로 추가할 때 그대로 사용
      Servo aiServo4;  // 6번

  ★ 스텝AiScan() 에도 aiServo3/aiServo4 분기가 이미 들어 있습니다.
     → 서보 선택 부분은 손댈 필요 없음.


  ▶ 서보가 5개 이상 필요하면?
  ─────────────────────────────────────────────────────────────────
    ① 파일 위쪽에  Servo aiServo5;  한 줄 추가
    ② stepAiScan() 의 else if 목록에  else if (aiWhich == 5) { aiServo5... }
       세 곳(끝날 때 / 매 스텝)에 추가
    ③ aiDispatch() 에 else if 블록 추가


  ▶ 스캔 방향 규칙 (홀수는 160→10, 짝수는 10→160)
  ─────────────────────────────────────────────────────────────────
    홀수 aiWhich :  aiP = 160; aiDir = -1; aiStart = 160; aiEnd = 10;
    짝수 aiWhich :  aiP =  10; aiDir =  1; aiStart =  10; aiEnd = 160;
    ※ 방향을 바꾸고 싶으면 이 네 값만 바꾸면 됩니다.


══════════════════════════════════════════════════════════════════════
 ★★ 기존 문법 늘리는 법 — handleLegacyCommand() 의 else if 를 복사
══════════════════════════════════════════════════════════════════════

  [방법 A] 완전히 새로운 문장
  ─────────────────────────────────────────────────────────────────
    예) "Led.mode" 를 추가하고 싶다면 → 두 곳에 코드를 넣는다

    ① 값 파싱 (기존 파싱 블록들 아래에)
       int leda = cmd.indexOf("Led.mode(");
       int ledb = cmd.indexOf(");");
       String ledResult = (leda >= 0 && ledb > leda)
                           ? cmd.substring(leda + 9, ledb) : "";

    ② 판정 블록 (▼▼▼ 위치에)
       else if (cmd.equals("Led.mode(" + ledResult + ");")) {
         pinMode(ledResult.toInt(), OUTPUT);
         digitalWrite(ledResult.toInt(), HIGH);
         return true;              // ★ matched 표시 필수!
       }

    ※ return true 를 빠뜨리면 아래 블록까지 내려가 오동작합니다.

  [방법 B] 있는 문법 수정 (예: Piano.mode 음계 바꾸기)
  ─────────────────────────────────────────────────────────────────
    handleLegacyCommand() 안의 해당 블록에서
    tone(7, 주파수, 1000);  의 주파수만 바꾸면 됩니다.

    도=262  레=294  미=330  파=349  솔=392  라=440  시=494  도=523


══════════════════════════════════════════════════════════════════════
 지원하는 기존 문장 (원본 그대로)
══════════════════════════════════════════════════════════════════════

    Piano.mode              초음파 거리 → 부저 음계
    Trash.mode              초음파 15cm 기준 서보 180°/85°
    digitalWrite(13,H);     디지털 HIGH
    digitalWrite(13,L);     디지털 LOW
    tone(7,262);            부저 소리
    noTone(7);              부저 정지
    if(cho < 11)            초음파 조건 → 서보/부저
    if(pos < 45)            모터 정방향
    if(pos > 135)           모터 역방향
    pos.write(m9,90);       서보 지정 위치
    BT.print(t10,e11);      초음파 측정값 BLE 회신
    int led = 13;           변수 안내
    Serial.print(7);        핀 상태 읽기
    stop                    모터 정지

 사용법
══════════════════════════════════════════════════════════════════════

  [업로드]
    1. Arduino IDE 에서 nubida_v11.ino 를 연다
    2. ★ 시리얼 모니터를 반드시 닫는다 (COM 점유 시 업로드 조용히 실패)
    3. 업로드
    4. 시리얼 모니터를 9600 으로 연다

  [업로드 성공 확인 — 맨 윗줄]
      === 누비다머신 통합 (AI분기 if/else if 형) v11 ===
      [빌드] Sep 14 2026 09:xx:xx     ← 이 줄이 보이면 새 펌웨어
      [AI] 1NubidaAi → 9번
      [AI] 2NubidaAi → 7번
      [기존] Piano.mode / Trash.mode / digitalWrite / tone 등
      준비 완료

    ⚠️ v8 / v9 / v10 배너가 보이면 업로드 실패입니다.
       시리얼 모니터를 닫고 다시 업로드하세요.

  [AI 값 테스트]      — 웹에서 카메라/음성 분류 → 자동 전송
  [기존 문장 테스트]  — 시리얼 모니터에 직접 입력 후 Enter

  [정상 로그]
      [복호화] xa6b8c7fcebe0ede8c8e0  →  1NubidaAi
      [AI] 1NubidaAi — 9번 스캔 시작
      [AI] 스캔 완료 — 서보 전원 해제

  [마지막 글자 유실돼도 OK]
      [복호화] x... → 1NubidaA       ← i 없음
      → startsWith("1Nubida") 로 인식 → 정상 스캔


══════════════════════════════════════════════════════════════════════
 안정화 기능 (v8 계열 — 지우지 마세요)
══════════════════════════════════════════════════════════════════════

  ① SoftwareSerial 64바이트 버퍼 함정 대응 (수신 최우선, rxBuf[256])
  ② 로그는 "프레임 완성 시" 1회만 → read() 지연 최소화
  ③ 수신 조각 붙이기 (30ms 무수신 = 프레임 완료)
  ④ loop() 안에 return; 금지 (서보 영구정지 방지)
  ⑤ 관대한 매칭 (마지막 글자 유실 / 앞자리만 도착)

  ⚠️ 새 기능을 추가할 때도 loop() 안에 return; 을 넣지 마세요.

 핀 배치
══════════════════════════════════════════════════════════════════════

  AT-09 BLE    : 2(RX), 3(TX)
  AI 서보 1    : 9번   (1NubidaAi)
  AI 서보 2    : 7번   (2NubidaAi)
  AI 서보 3    : 5번   (3NubidaAi — 주석 해제 시)
  AI 서보 4    : 6번   (4NubidaAi — 주석 해제 시)
  기존 서보    : 9번   (myServo — Piano.mode / Trash.mode 등)
  초음파 trig  : 10번, echo : 11번
  부저         : 7번
  모터 드라이버 : 4,5,6,7번

  ※ 9번을 AI 서보1 과 기존 서보가 함께 씁니다.
     한 쪽이 끝나면 detach() 로 전원을 해제하므로 충돌하지 않습니다.
  ※ 나노에서 서보 가능한 PWM 핀: 3, 5, 6, 9, 10, 11

 검증 이력
══════════════════════════════════════════════════════════════════════

  ✅ g++ -Wall 실제 컴파일 통과 (에러·경고 0)
  ✅ 괄호 균형: 중괄호 60/60, 괄호 447/447, 대괄호 5/5
  ✅ loop() 내 return; 0개
  ✅ aiDispatch() = if 1개 / else if 1개 / return true 2개 (요청한 형식)
  ✅ AI 판정 14케이스 전부 통과
  ✅ 오매칭 제거: "12" / "21" / "1x" / "2x" → AI 아님 (v10은 오인했음)
  ✅ 확장 실증: else if 한 블록 추가 → g++ 컴파일 통과 + 3번 인식 확인
