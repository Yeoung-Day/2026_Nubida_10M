■ 이 펌웨어가 하는 일
──────────────────────────────────────────────────────────────────────
  ① 기존 문장을 그대로 읽어서 동작
     (Piano.mode, Trash.mode, digitalWrite, tone …)
  ② 해시값(난독화 프레임)이 들어오면 AI 값도 동작
  ③ 두 가지가 한 코드에서 동시에 동작
  ④ ★ AI 값과 기존 문법을 "표 한 줄"로 늘릴 수 있음


══════════════════════════════════════════════════════════════════════
 ★★ AI 값 늘리는 법 (2군데만 고치면 끝)
══════════════════════════════════════════════════════════════════════

  [1단계] AI_SERVOS[] 에 서보 핀을 추가한다
  ───────────────────────────────────────────────────────────────────
    const uint8_t AI_SERVOS[] = { 9, 7 };
                                  ↑  ↑
                             1번째  2번째

    예) 3번째 서보를 5번 핀에 연결했다면:
    const uint8_t AI_SERVOS[] = { 9, 7, 5 };

    ※ 나노에서 서보를 쓸 수 있는 PWM 핀: 3, 5, 6, 9, 10, 11

  [2단계] AI_COMMANDS[] 표에 한 줄 추가한다
  ───────────────────────────────────────────────────────────────────
    const AiCommand AI_COMMANDS[] = {
      { "1NubidaAi", 1 },   // → 9번
      { "2NubidaAi", 2 },   // → 7번
      { "3NubidaAi", 3 },   // ← 요렇게 한 줄 추가 (→ 5번)
    };

    앞 문자열 = 웹에서 오는 AI 값
    뒤 숫자   = AI_SERVOS 의 몇 번째인지 (1부터)


  ▶ 이 두 줄만 고치면 끝. 아래 로직은 절대 건드릴 필요 없음.
     (matchAiCommand / startAiScan 이 표를 읽어서 자동 처리)

  ▶ 서보가 1개든 8개든 동일한 방식. 개수 제한은 나노의 메모리뿐.


══════════════════════════════════════════════════════════════════════
 ★★ 기존 문법 늘리는 법
══════════════════════════════════════════════════════════════════════

  [방법 A] 완전히 새로운 문장 (원본처럼 자유 파싱)
  ───────────────────────────────────────────────────────────────────
    ① handleLegacyCommand() 안에서 cmd 에서 값을 뽑는다
    ② if 체인에 블록을 하나 추가한다

    예) "Led.mode" 라는 새 문장을 만들고 싶다면:

      // ① 파싱 (기존 파서들 아래에 추가)
      int leda = cmd.indexOf("Led.mode(");
      int ledb = cmd.indexOf(");");
      String ledResult = (leda >= 0 && ledb > leda)
                          ? cmd.substring(leda + 9, ledb) : "";

      // ② 판정 블록 (▼▼▼ 위치에 추가)
      else if (cmd.equals("Led.mode(" + ledResult + ");")) {
        pinMode(ledResult.toInt(), OUTPUT);
        digitalWrite(ledResult.toInt(), HIGH);
        return true;          // ★ matched 표시 필수
      }

    ※ return true 를 빠뜨리면 다음 블록까지 내려가 오동작합니다.

  [방법 B] 지금 있는 문법을 수정 (예: Piano.mode 음계 바꾸기)
  ───────────────────────────────────────────────────────────────────
    handleLegacyCommand() 안의 해당 블록에서
    tone(7, 주파수, 1000); 의 주파수만 바꾸면 됩니다.

    도=262  레=294  미=330  파=349  솔=392  라=440  시=494  도=523

  ▶ 기존 문법은 원본 코드 형식을 그대로 유지했습니다.
     원본에 있던 문장은 전부 옮겨져 있으니, 같은 방식으로 이어붙이면 됩니다.


══════════════════════════════════════════════════════════════════════
 사용법
══════════════════════════════════════════════════════════════════════

  [업로드]
    1. Arduino IDE 에서 이 .ino 파일을 연다
    2. ★ 시리얼 모니터를 반드시 닫는다 (COM 점유 시 업로드 조용히 실패)
    3. 업로드
    4. 시리얼 모니터를 9600 으로 연다

  [업로드 성공 확인]
    맨 윗줄에 이렇게 나오면 성공:
      === 누비다머신 통합 (확장형) v10 ===
      [빌드] Sep 14 2026 09:xx:xx      ← 이 줄이 보이면 새 펌웨어가 올라간 것
      [AI] 서보 2개 / 명령 2개 등록
           1NubidaAi → 9번
           2NubidaAi → 7번
      [기존] Piano.mode / Trash.mode / digitalWrite / tone 등
      준비 완료

    ⚠️ v8 / v9 배너가 보이면 업로드 실패입니다.
       시리얼 모니터를 닫고 다시 업로드하세요.

  [AI 값 테스트]  — 웹에서 카메라/음성 분류하면 자동 전송됨
  [기존 문장 테스트] — 시리얼 모니터에 직접 입력 후 Enter

      Piano.mode
      Trash.mode
      tone(7,262);
      noTone(7);
      digitalWrite(13,H);
      pos.write(m9,90);
      stop

  [정상 로그 예시]
      [복호화] xa6b8c7fcebe0ede8c8e0  →  1NubidaAi
      [판정] AI값 = 1NubidaAi
      [AI] 1NubidaAi — 9번 스캔 시작
      [AI] 스캔 완료 — 서보 전원 해제

  [마지막 글자가 유실돼도 동작함]
      [복호화] x... → 1NubidaA      ← 마지막 i 없음
      [보정] 접두어로 인식 → 정상 스캔


══════════════════════════════════════════════════════════════════════
 안정화 기능 (v8 에서 계승 — 지우지 마세요)
══════════════════════════════════════════════════════════════════════

  ① SoftwareSerial 버퍼 64바이트 함정 대응
     → 수신을 최우선으로 돌리고, char rxBuf[256] 로 넉넉히
  ② 로그는 "프레임 완성 시" 1회만 → read() 지연 최소화
  ③ 수신 조각 붙이기 대기 (30ms 무수신 = 프레임 완료)
  ④ loop() 안에 return; 금지 (서보 영구정지 방지)
  ⑤ 관대한 매칭 (마지막 글자 유실 / 앞자리만 도착 대응)

  ⚠️ 새 기능을 추가할 때도 loop() 안에 return; 을 넣지 마세요.
     필요하면 플래그로 건너뛰세요.
